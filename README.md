# Words

Click "Code" in the top right corner, then click "Download ZIP".

Then drag and drop the Words-main.zip file into ChatOSS Apps > Library to install and use Words in the ChatOSS desktop app.

Words only runs on the ChatOSS desktop app.

You can download the ChatOSS desktop app here: https://chatoss.ai

You can also git clone the project to open the app in the ChatOSS Create app to have the ability to update the app if you want any additional features.

Words is open source. PRs are welcome.
